    • javaScript

    javaScript é uma linguagem de programação leve e interpretada, amplamente utilizada para criar páginas web interativas e didáticas .

    Ele é uma das três tecnologias principais da web (juntamente com HTML e CSS) e é suportado por todos os navegadores modernos sem a necessidade de pligins adicionais.

    O que ele faz

    • Criar menus dinâmicos e efeitos visuais.
    • Validar formulários antes de enviá-los.
    • Mostrar mensagens, pop-ups e notificações.
    • Controlar animações e eventos de clique.
    • Atualizar dados sem recarregar a página (com AJAX e APIs).
    • Contruir aplicações completas (front-end + back-end com Node.js).

    Como adicionar javaScript ao HTML

    • inline (na propria tag HTML)

      <button onclick="alert('Olá!')">Clique aqui</button>


    • interno (dentro da tag script)

      <script>
      alert("Bem-vindo!");
      </script>


    • Externo (arquivos .js separado)

      <script src="script.js"></script>


    O mais recomendado é o método externo por ser moderno e manter o código organizado e fácil de manter.

    sintaxe básica

    O javaScript é composto por instruções, variáveis, funções e eventos.

    Exemplo simples:

    let nome = "João";
    alert("Olá, " + nome + "!");

    Aqui, o JS cria uma variável nome e exibe uma saudação na tela

    Variáveis

    Usadas para armazenar informasções temporárias.

    let idade = 20; // pode mudar
    const PI = 3.14; // constante
    var cidade = "SP"; // antigo (ecite usar)

    Tipos de dados

    • string (texto): "Olá, mundo!"
    • number (número): 42
    • boolean (lógico): true ou false
    • array (lista): ["Maçã", "banana", "uva"]
    • object (objeto): { nome: "João", idade: 25 }

    Operadores

    let soma = 10 + 5; // adição
    let nomeCompleto = "Ana" + "Silva"; // concatenação
    let maior = 10 > 5; // comparação (true)

    funções

    Os eventos permitem reagir ás ações do usuário — como clique, digitação, movimento do mouse...

    <button onclick="mudarTexto()">Clique aqui</button>

    <p id="demo">Texto original</p>

    <script>
    function mudarTexto() {
    document.getElemntById("demo").innerHTML = "texto alterado!";
    }
    </script>

    Quando o botão é clicado, o texto do parágrafo muda instantaneamente.

    DOM

    O DOM é a ponte entre o javaScript e o HTML.

    Ele transforma a página em um aárvore de elemntos, permitindo que o JS leia e midifque o conteúdo.

    Exemplo:

    document.body.style.backgroundColor = "lightblue";

    Esse código altera a cor de fundo da página para azul claro.

    Comentários

    Comentários servem para explicar partes do código:

    // comentário de uma linha

    /*
    comentário de multiplas linhas
    */

    Boas práticas

    • Use nomes claros para variáveis e funções.
    • Sempre idente e organize o código.
    • Evite códigos inline — prefira arquivos externos.
    • Teste no console do navegador (F12 > console).
    • Documente suas funções para facilitar manutenção.

    Exemplo prático

    <!DOCTYPE html>
    <html lang="pt-BR">
    <head>
    <meta charset="UTF-8">
    <title>Exemplo JS</title>
    </head>
    <body>
    <h1 id="titulo"Olá, visitante!</h1>
    <button onclick="mudar()">Clique para mudar</button>

    <script>
    function mudar() {
    document.getElemnteById("titulo"). innerHTML = "Você clicou!";
    }
    </script>
    </body>
    </html>

    Aqui o javaScript modifica o conteúdo da página em tempo real.

    Eventos comuns em javaScript

    Eventos são ações ou ocorrências que acontecem na página e às quais o javaScript pode reagir. por exemplo: um clique, uma tecla pressionada, o carregamneto da página, entre outros.

    Eventos de mouse

    Evento Descrição
    onclick Dispara quando o elemento é clicado
    ondblclick Dispara ao clicar duas vezes
    onmouseover Quando o cursor passa sobre o elemnto
    onmouseout Quando o cursor sai do elemnto
    onmousedown Quando o botão do mouse é pressionado
    onmouseup Quando o botão do mouse é souto

    Exemplo:

    <button onclick="alert("Você clicou!")">Clique aqui</button>

    Eventos de teclado

    Evento Descrição
    onkeydown Quando uma tecla é pressionada
    onkeyup Quando uma tecla é solta
    onkeypress Quando uma tecla é pressionada (deprecated em alguns navegadores)

    Exemplo:

    <input onkeydown="console.log('Tecla pressionada')" placeholder="Digite algo">

    Eventos de formulários

    Evento Descrição
    onsubmit Quando o formulário é enviado
    onfocus Quando o campo recebe foco
    onblur Quando o campo perde o foco
    onchange Quando o valor de um campo é alterado

    Exemplo:

    <form onsubmit="alert('formulário enviado!')">
    <input type="text" onfocus="this.style.background='lightblue'">
    <button>Enviar</button>
    </form>

    Eventos da janela (windows)

    Evento Descrição
    onload Quando a página termina de carregar
    onresize Quando a janela é redimencionada
    onscroll Quando o usuário rola a página
    onunload quando o usuário sai da página

    Exemplo:

    <body onload="console.log('página carregada!')">

    Formas Modernas de usar eventos

    Usar addEventListener() é a forma mais limpa e atual:

    ducumnet.querySelector("button").addeventListener("click", () => {
    alert("Botão clicado!");
    });
