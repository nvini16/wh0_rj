# wh0_rj - &rarr;Este manual apresenta os fundamentos essenciais da programação web, abordando de forma prática as linguagens HTML, CSS e JavaScript.

O conteúdo inclui:

HTML: estrutura, tags e atributos.

CSS: estilos, layouts e responsividade.

JavaScript: lógica, interatividade e eventos.

Plataformas de estudo e boas práticas.

O objetivo é fornecer uma base sólida para iniciantes compreenderem como a web funciona e desenvolverem páginas completas — unindo estrutura, estilo e lógica.
