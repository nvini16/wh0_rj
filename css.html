    Introdução

    Introdução ao CSS (Cascading Style Sheets)

    O CSS —Cascading Style Sheets ou Folhas de estilo em cascata — é uma linguagem usada para definir o estilo visual e o layout de documentos HTML.


    Enquanto o HTML cria a estrutura da página, o CSS é responsável pela aparência: cores, fontes, espaçamentos, posicionamento e até animações.

    Objetivo

    Permitir que você separe o conteúdo (HTML) da apresentação (CSS).

    Isso facilita a manutenção e o design consistente em várias páginas web.

    Formas de aplicar CSS

    • Inline (na própria tag HTML)

      <p style="color: blue;">Texto azul</p>

      Útil apenas em testes rápidos!


    • Interno (dentro da tag <style> no HTML)

      <style>

      p {
      color: blue;

      </style>

      Bom para páginas únicas!


    • Externo (arquivo .css separado)

      <link rel="stylesheet" href="estilos.css">

      É o método profissional. Mantém o código limpo e facilita atualizações!


    Sintaxe básica do CSS

    seletor{
    propriedade: valor;
    }

    Exemplo:

    h1 {
    color: red;
    font-size: 24px;
    }

    Aqui, o seletor h1aplica a cor vermelha e o tamanho de 24px a todos os títulosh1.

    Seletores principais

    • seletor de tag: p { color: gray; }
    • seletor de classe: .destaque { background: yellow; }
    • seletor de ID: #título { font-size: 30px; }
    • seletor aninhado: div p { color: green; }
    • seletor universal: * { margin: 0; padding: 0; }

    Principais propriedades

    Categoria Exemplos
    Texto color, font-size, font-family, text-align
    Espaçamento margin, padding, line-height
    Tamanho e forma width, height, border, border-radius
    Fundo backgound-color, backgroun-image, backgroun-size
    Layout display, position, flex, grid, float
    Efeitos box-shadow, opacity, transition, animation

    Cascata e herança

    O nome Cascading vem do modo como o CSS decide qual estilo aplicar quando há conflitos.
    As regras seguem uma ordem de propriedade:

    1. inline
    2. interno
    3. externo
    4. herança e especificidade

    Exemplo:

    <style>

    p { color: blue; } /* externo */
    </style>

    <p style="color: red;">Texto vermelho</p> /* inline */

    O texto será vermelho, porque o estilo inline tem propriedade sobre o de classe.

    Boas práticas

    • Use classe para aplicar estilos em grupos de elemntos.
    • Mantenha o CSS externo separado do HTML.
    • Dê nomes claros e semânticos ás classes (.menu-princial, .botao-enviar).
    • Evite repetir código: aproveite a herança e o reuso.
    • Comente o código sempre que criar algo importante:

    /* seção principal do site */

    Exemplo:

    <!DOCTYPE html>
    <html lang="pt-BR">
    <head>
    <meta charset="UTF-8">
    <titlie>Exemplo CSS</title>
    <link rel="stylesheet" href="style.css">
    </head>
    <body>
    <h1 class="titulo">Bem-vindo ao meu site!</h1>
    <p>Este é um exemplo com CSS externo.</p>
    </body>
    </html>


    /* style.css */

    body {
    background-color: #f4f4f4;
    font-family: Arial, sans-serif;
    color: #333;
    }

    .titulo {
    color: #007bff;
    text-align: center;
    }
