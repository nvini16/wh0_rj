Introdução ao CSS (Cascading Style Sheets)

O CSS —Cascading Style Sheets ou Folhas de estilo em cascata — é uma linguagem usada para definir o estilo visual e o layout de documentos HTML.


Enquanto o HTML cria a estrutura da página, o CSS é responsável pela aparência: cores, fontes, espaçamentos, posicionamento e até animações.

Objetivo

Permitir que você separe o conteúdo (HTML) da apresentação (CSS).

Isso facilita a manutenção e o design consistente em várias páginas web.

Formas de aplicar CSS

  • Inline (na própria tag HTML)

    <p style="color: blue;">Texto azul</p>

    Útil apenas em testes rápidos!


  • Interno (dentro da tag <style> no HTML)

    <style>

    p {
    color: blue;

    </style>

    Bom para páginas únicas!


  • Externo (arquivo .css separado)

    <link rel="stylesheet" href="estilos.css">

    É o método profissional. Mantém o código limpo e facilita atualizações!
